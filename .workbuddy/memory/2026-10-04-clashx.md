## 上游调研结论（SSClash /讨论 #1325）
参考实现是**两段式**：
  chain mangle { type filter hook prerouting priority -150; }  # 排除 + 打 mark
  chain proxy  { type filter hook prerouting priority -100; }  # tproxy
  chain output { type route  hook output    priority mangle; }  # ★ type route 而非 filter
已按此改过一版，**仍然不通**。

## nftables 语法坑（已踩，代码注释已记录）
- `inet` 表里 `ip daddr X ... tproxy` → conflicting protocols，必须用 `ip` 表或去掉 ip 限定
- tproxy 必须带 `meta l4proto tcp/udp`，否则报 "requires transport protocol match"
- `dnat` / `tproxy` 是 terminal statement，后面不能跟 `return` 或 `counter`
- `ip rule ... table clashx`（表名）→ invalid table ID，必须用数字表号
- 在 rt_tables 注册 `clashx 202` 会让整个文件 corrupted（Ubuntu 24.04 要求数字在前）
